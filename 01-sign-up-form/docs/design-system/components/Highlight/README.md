The Highlighter mark for quoted passages in notebooks — the only place Highlighter appears.

**Consumer provides:** the highlighted text, inline inside `note-quote` or `note-body` copy.

`highlighter` ground, `on-highlighter` text (10.9:1), `radius-sm` corners, wraps cleanly across lines. Never white text on it (1.6:1, fails), never a button, badge or link colour.
